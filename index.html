API key de Groq (para el Chat IA)

Se guarda solo en este dispositivo (localStorage del navegador). Nunca se envía a ningún servidor excepto a Groq directamente.

¿Cómo consigo mi API key gratis?
  1. Entrá a console.groq.com y creá una cuenta gratis (podés usar Google).
  2. En el menú lateral andá a API Keys.
  3. Tocá Create API Key, ponele un nombre (ej. "italiano-app") y confirmá.
  4. Copiá la key que empieza con gsk_... (solo se muestra una vez).
  5. Pegala acá arriba y tocá "Guardar API key".
¿Cómo instalo la app en el celular?
  1. Android (Chrome): tocá el menú ⋮ arriba a la derecha del navegador y elegí "Agregar a pantalla de inicio" o "Instalar app".
  2. iPhone (Safari): tocá el ícono de compartir (el cuadrado con la flecha hacia arriba) y elegí "Añadir a pantalla de inicio".
  3. Confirmá el nombre (Tanapp) y tocá "Agregar". Va a quedar instalada con su propio ícono, y funciona sin conexión para Conjugar, Biblioteca (verbos ya guardados) y Tarjetas.
  4. Para que aparezca esta opción, la app tiene que estar servida por HTTPS (por ejemplo, ya publicada en Vercel o GitHub Pages) — abrir el archivo local no alcanza para instalarla.

¿Cómo funciona la racha?

Cada vez que respondés bien un ejercicio en "Conjugar", la racha 🔥 sube 1. Si te equivocás, vuelve a 0. "Mejor racha" guarda tu récord histórico, y nunca baja.

¿Y el repaso?

Cada frase que respondés queda anotada en un sistema de repetición espaciada: si la acertás, tarda más en volver a aparecer (1, 3, 7, 16 días); si te equivocás, vuelve a aparecer enseguida en la próxima tanda. Cuando hay verbos esperando, ves la tarjeta "Repaso pendiente" en Conjugar.

Verbos en -IRE con -isc- (ej. capire → cap-)

El resto de los tiempos (imperfetto, futuro, condizionale, congiuntivo imperfetto, passato remoto) son idénticos al grupo -IRE sin -isc-: capivo, capirò, capirei, capissi, capii... Gerundio: capendo · Participio passato: capito

Notas ortográficas

  • -care / -gare (cercare, pagare): agregan una "h" antes de e/i para mantener el sonido duro → cerco, cercherò, cerchi; pago, pagherò, paghi.
  • -ciare / -giare (cominciare, mangiare): pierden la "i" del radical antes de e/i → comincio, comincerò (no "-ciere"); mangio, mangerò.
  • -iare sin c/g (studiare, inviare): mantienen la "i" antes de desinencias en "e" pero la pierden antes de desinencias en "i" → tu studi (no "studii"), pero io studierò.

Auxiliar: avere o essere

En los tiempos compuestos (passato prossimo, trapassato...) la mayoría de los verbos usa avere (ho parlato). Un grupo más chico —verbos de movimiento, cambio de estado, reflexivos y "essere" mismo— usa essere (sono andato/andata), y ahí el participio concuerda en género y número con el sujeto.
