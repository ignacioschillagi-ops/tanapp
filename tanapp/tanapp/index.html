API key de Groq (para el Chat IA)

Se guarda solo en este dispositivo (localStorage del navegador). Nunca se envía a ningún servidor excepto a Groq directamente.

¿Cómo consigo mi API key gratis?
  1. Entrá a console.groq.com y creá una cuenta gratis (podés usar Google).
  2. En el menú lateral andá a API Keys.
  3. Tocá Create API Key, ponele un nombre (ej. "italiano-app") y confirmá.
  4. Copiá la key que empieza con gsk_... (solo se muestra una vez).
  5. Pegala acá arriba y tocá "Guardar API key".
